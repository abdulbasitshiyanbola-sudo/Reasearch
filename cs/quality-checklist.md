# CS Task Quality Checklist

Run through this before submission. Every box must be checkable.

## A. Question construction (§1.2 DOs)

- [ ] **Challenging & reasoning-heavy** — not answerable by reading/lookup alone.
- [ ] **Self-contained** — an expert could solve it without the paper. All assumptions,
      models, inputs, constraints, boundary/initial conditions stated explicitly.
- [ ] **Single question** — exactly one question requiring one answer.
- [ ] **Single correct answer** — no alternative valid answers.
- [ ] **LaTeX** used for all mathematical symbols, and it **renders**.
- [ ] **Numeric precision** specified when relevant (e.g., "round to 3 significant figures").
- [ ] **Canonical form / convention** specified when relevant (e.g., "two words",
      "as a percentage", "lowercase gene symbol").
- [ ] Golden answer and full verifiable solution are **correct**.

## B. Prohibited patterns (§1.2 DON'Ts)

- [ ] NOT a trivial lookup from the paper.
- [ ] NOT more than one possible answer.
- [ ] NOT multiple questions in one prompt.
- [ ] LaTeX does NOT fail to render.
- [ ] Does NOT use the phrases "in the paper" or "in the reference".
- [ ] Answer is NOT one of {`-1`, `0`, `1`, `Yes`, `No`}.
- [ ] Answer is **≤ 60 characters**.
- [ ] NOT multiple choice.
- [ ] NOT fill-in-the-blank.

## C. Source paper (§1.3)

- [ ] Paper license is one of: Apache, MIT, CC BY, CC BY-SA, CC0, BSD (verified per paper).
- [ ] The paper's specific result/lemma/technique makes the problem **easier**
      (supports Run III), without being a copy of the answer.

## D. Uniqueness (§1.6)

- [ ] Paper used ≤ 3 times total (prefer once).
- [ ] Problem is distinct (passes the built-in duplicate check).
- [ ] Question not taken from any online/other source.
- [ ] Question not generated by AI/LLM (§1.6.3).

## E. Novelty (A2)

- [ ] Novelty check performed; Perplexity results URL recorded on the task.

## F. Pass-rate gates (Opus 4.8 or latest; 3 runs × 16 attempts)

**Full Difficulty**
- [ ] Run I (no paper, no web): passes in **0–2** → pass rate **≤ 12.5%**.
- [ ] Run II (no paper, web): no restriction.
- [ ] Run III (paper, no web): passes in **1–8** → pass rate **≤ 50%**.
- [ ] Run I **or** Run II has ≥ 1 pass (else extend to ≤ 32 attempts to obtain one).
- [ ] Run III passes **>** Run I passes.

**Easier Difficulty (Criteria 2, optional)**
- [ ] Run I (no paper, no web): passes in **0–8** → pass rate **≤ 50%**.
- [ ] Run II (no paper, web): no restriction.
- [ ] Run III (paper, no web): passes in **1–12** → pass rate **≤ 80%**.
- [ ] Run I **or** Run II has ≥ 1 pass (else extend to ≤ 32 attempts to obtain one).
- [ ] Run III passes **>** Run I passes.

## G. Consistency

- [ ] Prompt and answer(s) are consistent across run1, run2, run3 (checked on Taiga
      before submitting on the Eval Platform).
